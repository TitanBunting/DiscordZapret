> WinDivert нужен zapret для перехвата и фильтрации сетевого трафика.
> Этот инструмент могут применять как безопасные, так и вредоносные программы, однако сам WinDivert вирусом не является.
>
> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) из репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов классифицирует файлы WinDivert как инструменты повышенного риска или хакерские утилиты. В результате файл удаляется и перемещается в карантин. Название обнаружения обычно содержит `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте каталог с zapret в исключения антивируса либо отключите проверку PUA — потенциально нежелательных приложений. Например, в Kaspersky есть параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы уверенно понимаете настройки исключений, лучше добавить исключение. В противном случае рекомендуется отключить обнаружение PUA.

## ⚙️Использование

1. Сначала включите безопасный DNS (Secure DNS)
    * В Chrome откройте пункт "Использовать безопасный DNS" и выберите поставщика, отличного от "Поставщик по умолчанию"
    * В Firefox включите "DNS через HTTPS", установите режим "Персональный", затем выберите "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован
    * Windows 11 позволяет включить Secure DNS непосредственно в параметрах системы — [инструкция находится здесь](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот вариант рекомендуется
    * На роутерах Keenetic активируйте параметр "Транзит запросов". При отключении этой опции Secure DNS на компьютере может работать некорректно

2. Загрузите zip- или rar-архив со [страницы последнего релиза](https://github.com/TitanBunting/zapret-discord-youtube/releases/latest)

3. Откройте свойства загруженного архива и включите "Разблокировать". Для архивов, открытых через 7-Zip или PeaZip, этот пункт можно не выполнять

4. Распакуйте архив в каталог, путь к которому не содержит кириллицу и специальные символы

5. Запустите подходящий файл
    * Для поиска рабочей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Чтобы включить автозапуск, выберите **`service.bat`** -> `Install Service` -> *нужную стратегию*

## ℹ️Кратко о файлах

- [**`general.bat ...`**](./general.bat) — ручной запуск стратегии

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества факторов, поэтому **перебирайте стратегии (ALT, FAKE и другие), пока не найдёте подходящую именно для вас**

- [**`service.bat`**](./service.bat) — автозапуск и дополнительные операции:
  - <ins>**`Install Service`** — добавить выбранную стратегию в автозапуск через services.msc</ins>
  - **`Remove Services`** — удалить стратегию и WinDivert из списка служб
  - **`Check Status`** — посмотреть состояние обхода и служб, включая стратегию в автозапуске и WinDivert
  - **`Game Filter`** — включить или отключить обход для игр и других сервисов, использующих UDP и TCP на портах выше 1023.  
  **После изменения параметра стратегию нужно перезапустить.**  
  Текущее состояние указано в скобках: включено или выключено.
  - **`IPSet Filter`** — выбрать режим обработки сервисов из `ipset-all.txt`.  
  Этот параметр пригодится при проверке ресурса, который без zapret работает нормально  
  В скобках отображается текущий режим:
    - `none` — IP-адреса не проходят проверку
    - `loaded` — IP проверяется на наличие в списке
    - `any` — под фильтр попадает любой IP  
  - **`Auto-Update Check`** — включить или отключить автоматическую проверку обновлений
  - **`Replace active fakes`** — заменить используемый fake на другой из каталога `bin`
  - **`Update IPSet List`** — загрузить актуальный `ipset-all.txt` из репозитория
  - **`Update Hosts File`** — обновить hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**</ins>
  - **`Check for Updates`** — вручную проверить наличие обновлений
  - **`Run Diagnostics`** — найти распространённые причины неисправности zapret.  
  В финале можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает при внезапном отказе приложения
  - **`Run Tests`** — открыть инструмент тестирования стратегий:
    - `Standard tests` — проверить сайты из `utils/targets.txt`
    - `DPI checkers` — проверить DPI разных провайдеров, включая Cloudflare и Amazon


## ☑️Частые вопросы и неисправности

### После запуска `general*` нет никакой реакции

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться winws.exe — процесс обхода, видимый на панели задач.  
Если его нет, обратитесь к [#522](https://github.com/TitanBunting/zapret-discord-youtube/issues/522)

### Не работает ни одна стратегия
- Откройте командную строку с правами администратора
- По очереди выполните следующие команды:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер

### Не открывается Telegram в браузере
Запустите **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь содержимое открывшегося блокнота
  - Откройте файл `hosts` в созданной папке через текстовый редактор, запущенный от имени администратора
  - Вставьте скопированный текст в конец `hosts` либо замените ранее добавленный аналогичный блок
  - Сохраните файл и снова проверьте соединение. Если результата нет, убедитесь, что изменения действительно записались.

#### Результат не гарантируется. Если способ не помог, используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/TitanBunting/tg-ws-proxy) или любым публичным прокси.

### Обход не запускается или больше не работает

> [!IMPORTANT]
> **Стратегии не обязательно работают постоянно.**
> Даже эффективная в течение некоторого времени стратегия может перестать работать после её обнаружения.
> Здесь собрано много вариантов обхода. Если готовые стратегии не дают результата, создайте новую на основе одной из них, изменив её параметры.
> Описание параметров доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Убедитесь, что в `service.bat` -> `Run Diagnostics` не отображаются ошибки

- Проверьте, что адрес нужного ресурса присутствует в списках доменов или IP-адресов

- Переключитесь на другие стратегии, например **`ALT`** или **`FAKE`**

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация: [#765](https://github.com/TitanBunting/zapret-discord-youtube/issues/765)

### Как полностью переустановить или обновить проект?
- Сохраните ресурсы и данные, которые добавляли самостоятельно
- Перезагрузите устройство
- Откройте `service.bat` -> `Remove Services`
- Запустите `service.bat` -> `Run Diagnostics`; если найдены ошибки, устраните их и в конце выберите Y
- Удалите каталог zapret
- Загрузите свежую версию [со страницы релизов](https://github.com/TitanBunting/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Нажмите правой кнопкой по архиву и откройте свойства. Если внизу есть пункт разблокировки, включите его, нажмите применить и подтвердите выбор
- Распакуйте архив в новый каталог в корне диска, избегая пробелов и специальных символов
- Запускайте разные скрипты `general` и проверяйте интернет-ресурсы. Если соединения нет, закройте программу через значок замка на панели задач и попробуйте другой вариант
- После выбора рабочей стратегии добавьте её в автозапуск через `service.bat` -> `Install Service` -> выбранная стратегия

### Игра или приложение не работает при активном zapret

- Проверьте в service.bat, что `Game Filter` установлен в **`disabled`**, а `IPSet Filter` — в **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит сообщает о проблеме с WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- Замените `WinDivert.dll` и `WinDivert64.sys` в каталоге [`bin`](./bin) одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё есть среди служб

1. Получите имя службы командой в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите службу и удалите её следующими командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, включён ли [Secure DNS](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал активно с ними бороться.
- Переберите остальные стратегии, особенно если раньше всё работало.
- См. также [#251](https://github.com/TitanBunting/zapret-discord-youtube/discussions/251)

### Не запускается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS](#%EF%B8%8Fиспользование) настроен
- Сначала желательно определить стратегию, на которой открывается сайт YouTube, и запустить её
- В `service.bat` выберите `Run Diagnostics`, затем очистите кэш Discord
- Проверьте работу приложения Discord после очистки кэша
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно пользоваться ей
- Если Discord не подключается и в браузере, проверьте все остальные стратегии. YouTube и Discord могут работать на разных вариантах
- См. также [#252](https://github.com/TitanBunting/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Воспользуйтесь [tg-ws-proxy](https://github.com/TitanBunting/tg-ws-proxy)
- Либо подключитесь к бесплатному MTProto-прокси из интернета

### Игры не работают

Игр много, поэтому проверить и исправить каждую из них невозможно.

Обычно стоит действовать так:
- через `service.bat` обновите ipset и активируйте `Game Filter`
- если это не решит проблему, дополнительно включите `ipset any`

Учтите: режим `ipset any` может нарушить открытие множества сайтов. Не оставляйте его включённым постоянно. Определите IP-адреса, которые использует игра, и внесите их в `ipset-all.txt`

Если проблема сохраняется, создайте обсуждение в разделе [Discussions](https://github.com/TitanBunting/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи от других игроков.

### В списке нет моей проблемы

- Опишите её [здесь](https://github.com/TitanBunting/zapret-discord-youtube/issues)

## 🗒️Добавление адресов других ресурсов

Расширить перечень адресов для обхода можно с помощью следующих файлов:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** — домены-исключения, например когда IP-сеть указана в `ipset-all.txt`, но конкретный домен из неё фильтровать не нужно
- **`ipset-all.txt`** — IP-адреса и подсети
- **`ipset-exclude-user.txt`** — IP-адреса и подсети, которые следует исключить
  - Файлы **`*-user.txt`** автоматически появляются при первом запуске `zapret` или `service.bat`
